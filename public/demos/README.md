# Demo audio

## Moonlight Sonata

- Work: Ludwig van Beethoven, Piano Sonata No. 14 in C-sharp minor, Op. 27 No. 2, first movement (Adagio sostenuto).
- Source: [Moonlight Sonata.ogg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Moonlight_Sonata.ogg), uploaded by ComputerHotline on May 17, 2006.
- Original file: https://upload.wikimedia.org/wikipedia/commons/d/d0/Moonlight_Sonata.ogg
- The source is a rendering of the Mutopia MIDI, based on the Berners 1908 edition edited by A. Winterberger. It is a synthesized performance, not a commercial recording.
- License: the Commons file page identifies it as public domain, including related and neighboring rights ([Public Domain Mark 1.0](https://creativecommons.org/publicdomain/mark/1.0/)).
- Local modification: converted to 128 kbps MP3 with FFmpeg; the full first movement is preserved (approximately 5:07).

## Für Elise

- Work: Ludwig van Beethoven, Bagatelle No. 25 in A minor, WoO 59 (Für Elise).
- Performance: V. Gao (Wikimedia Commons user Gaodifan), recorded July 18, 2006.
- Source: [FurElise.ogg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:FurElise.ogg).
- Original file: https://upload.wikimedia.org/wikipedia/commons/7/7b/FurElise.ogg
- License: the performer released this recording into the public domain; the Commons file page also identifies it under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/), including related and neighboring rights.
- Local modification: converted to 128 kbps MP3 with FFmpeg; the full performance is preserved (approximately 2:57).
